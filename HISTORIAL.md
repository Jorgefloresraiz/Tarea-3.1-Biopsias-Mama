# Procedencia del historial

El estudiante realizó las correcciones en Colab antes de crear este repositorio. Con su autorización se organizan ahora commits retrospectivos por cambio, con fechas reales de creación. No representan una secuencia de ejecuciones locales pasadas.

El primer commit conserva el notebook recibido. Los estados intermedios muestran cambios de código sin outputs inventados. El último estado del notebook conserva byte por byte el archivo descargado de Colab, incluidas sus salidas. Las pruebas posteriores se ejecutaron realmente sobre las funciones extraídas.
